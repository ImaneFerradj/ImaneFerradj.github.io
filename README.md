# Imane Ferradj — Personal Website V4

This version removes the downloadable CV PDF entirely.

## Structure

- `index.html` — short visual home page
- `resume.html` — detailed academic profile / web résumé
- `publications.html` — publications and submitted manuscripts
- `assets/styles.css`
- `assets/script.js`
- `assets/imane-ferradj-hero.png`

The structure is inspired by the organization of an academic personal site:
a concise home page, a detailed profile, and a dedicated publications page.
The visual treatment is intentionally smoother, lighter, and more product-like.

## GitHub Pages

Upload these files and the `assets` folder to the root of
`ImaneFerradj/ImaneFerradj.github.io`.

No CV PDF is needed.

## Privacy

The phone number from the source résumé is not exposed on the website.
